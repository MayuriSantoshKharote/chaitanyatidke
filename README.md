# Chaitanya's Digital Hub

A modern and responsive personal portfolio website created for **Chaitanya Manik Tidke**, a Digital Marketing and Social Media Professional.

The portfolio presents his skills, experience, projects, certifications, achievements, and contact information through a professional dark-themed interface.

## Running the Project Locally

Make sure Node.js and npm are installed on your computer.

```bash
git clone PASTE_YOUR_GITHUB_REPOSITORY_URL_HERE
cd chaitanya-digital-hub
npm install
npm run dev
```

Open the local URL displayed in the terminal.

## Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally, run:

```bash
npm run preview
```

## Deployment

The website is deployed using **Vercel**. Updates pushed to the connected GitHub repository can be deployed automatically through Vercel.
